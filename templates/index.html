Command Directory

Explore the full list of available commands and automated features.

$kick @user [reason] Moderation
Kick a specified member from the server.
$ban @user [reason] Moderation
Ban a user permanently by mention or user ID.
$mute @user <time> [reason] Moderation
Apply timeout duration to a member (e.g. 10m, 1h, 1d).
$warn @user <reason> Moderation
Issue a warning to a member (persisted & DMs user).
$purge <count> Moderation
Bulk delete 1 to 100 recent messages in channel.
$lock / $unlock Moderation
Lock or unlock send message permissions for @everyone.
$stats Info
View live server member counts, channels, and warnings.
$userinfo [@user] Info
Display user join date, roles, and warning history.

Roll a dice or flip a coin for quick decision making.
